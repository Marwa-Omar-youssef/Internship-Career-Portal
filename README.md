# Internship & Career Portal (ICP)

## Project Overview

The **Internship & Career Portal (ICP)** is a web-based platform designed to connect students with recruiters and internship opportunities. It aims to simplify the internship application process, help students explore opportunities that match their skills and interests, and enable recruiters to manage internship listings and applications.

## Main Features

- Student and recruiter account registration and login.
- Student profile and skills management.
- Internship opportunity browsing and searching.
- Internship application submission and tracking.
- Recruiter opportunity creation and management.
- Application review and status updates.
- Notifications for relevant application activities.
- Skill gap analysis to help students identify missing skills.
